# Security Policy

Only the current Chrome Web Store release is supported.

**Please don't open a public issue for a security problem.** Report it through
[GitHub's advisory form](https://github.com/madebybahar/bayaaz/security/advisories/new),
which stays private until a fix ships.

Please don't attach private reading material — an article you clipped, a private
URL, anything you would rather not publish. Bayaaz works on whatever page you
are on, so an invented page that reproduces the same problem is more useful here.

This is a one-person project, so replies are not always quick. You will hear
where a valid report stands, and you are credited in the release notes unless
you would rather not be.

# 安全策略

只支持 Chrome 应用商店上的当前版本。

**请不要用公开 issue 报告安全问题。** 请走
[GitHub 的私密通报表单](https://github.com/madebybahar/bayaaz/security/advisories/new)，
在修复发布之前它一直不公开。

请不要附上私人阅读内容——剪藏下来的文章、私密网址，以及任何你不愿公开的东西。Bayaaz
在你正打开的任何页面上工作，一段能复现同样问题的虚构内容，在这里更有用。

这是一个人的项目，回复未必及时。确认属实的报告，进展会告诉你；也会写进发布说明致谢，
除非本人不愿具名。
