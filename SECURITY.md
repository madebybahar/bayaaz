# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.4.x | ✅ |
| < 1.4 | ❌ — please update through the Chrome Web Store |

Bayaaz runs entirely in the browser. It has no account, no server, and makes no
network requests, so a vulnerability here affects the person running the
extension rather than anyone else's data.

## Reporting a vulnerability

**Please don't open a public issue for a security problem.** Report it privately
through [GitHub's advisory form](https://github.com/madebybahar/bayaaz/security/advisories/new),
which is visible only to the maintainer until a fix ships.

Useful things to include: the extension version, your Chrome version and
operating system, what an attacker could do, and the smallest steps that
reproduce it. Please don't attach private reading material — Bayaaz works on
whatever page you are on, and an invented page that reproduces the same problem
is more useful here.

This is a one-person project. Expect a first reply within a week; if a report
turns out to be valid, the fix and its Chrome Web Store review will take longer
than that, and you will hear where it stands.

## Credit

Anyone who reports a valid issue is credited in the release notes, unless they
would rather not be.

# 安全策略

## 支持的版本

| 版本 | 是否支持 |
|---|---|
| 1.4.x | ✅ |
| 低于 1.4 | ❌ —— 请从 Chrome 应用商店更新 |

Bayaaz 完全在浏览器里运行，没有账号、没有服务器、不发任何网络请求，所以这里的漏洞
影响的是运行这个扩展的人，而不是别人的数据。

## 如何报告漏洞

**请不要用公开 issue 报告安全问题。** 请走
[GitHub 的私密通报表单](https://github.com/madebybahar/bayaaz/security/advisories/new)，
在修复发布之前，只有维护者看得到。

有用的信息：扩展版本、Chrome 版本与操作系统、攻击者能做到什么、以及能复现的最小步骤。
请不要附上私人阅读内容——Bayaaz 在你正打开的任何页面上工作，一段能复现同样问题的虚构
内容，在这里更有用。

这是一个人的项目。首次回复请预期一周之内；若确认属实，修复加上 Chrome 应用商店的审核
会比这更久，进展会告诉你。

## 署名

报告有效问题的人，都会写进发布说明致谢，除非本人不愿具名。
