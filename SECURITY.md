# Security Policy

## Supported versions

The current release is the supported one. Chrome updates the extension on its
own, so what you have installed is almost certainly it; if you loaded an older
tag unpacked, update before reporting.

Bayaaz runs entirely in the browser. It has no account, no server, and makes no
network requests, so a vulnerability here reaches the person running the
extension, not anyone else's data.

## Reporting a vulnerability

**Please don't open a public issue for a security problem.** Report it through
[GitHub's advisory form](https://github.com/madebybahar/bayaaz/security/advisories/new),
which stays private until a fix ships.

Useful things to include, in this order: what someone could do with it, the
smallest steps that reproduce it, and the versions you were running — Bayaaz,
Chrome, and your operating system.

Please don't attach private reading material. Bayaaz works on whatever page you
are on, so the page behind a security bug is often one you would rather not
publish; an invented page that reproduces the same problem is more useful here.

This is a one-person project. Expect a first reply within a week. Fixing a valid
report takes longer, because the fix then waits on Chrome Web Store review, and
you will hear where it stands.

## Credit

Anyone who reports a valid issue is credited in the release notes, unless they
would rather not be.

# 安全策略

## 支持的版本

支持当前发布版。Chrome 会自动更新扩展，所以你装的几乎必然就是它；若你从旧标签加载了
未打包版本，请先更新再报告。

Bayaaz 完全在浏览器里运行，没有账号、没有服务器、不发任何网络请求，所以这里的漏洞
波及的是运行这个扩展的人，不是别人的数据。

## 如何报告漏洞

**请不要用公开 issue 报告安全问题。** 请走
[GitHub 的私密通报表单](https://github.com/madebybahar/bayaaz/security/advisories/new)，
在修复发布之前它一直不公开。

有用的信息，按这个顺序：有人能拿它做到什么、能复现的最小步骤、以及你所用的版本，包括
Bayaaz、Chrome 和操作系统。

请不要附上私人阅读内容。Bayaaz 在你正打开的任何页面上工作，安全问题背后那一页，往往
是你并不想公开的；一段能复现同样问题的虚构内容，在这里更有用。

这是一个人的项目。首次回复请预期一周之内。修好一个确认属实的问题要更久，因为修完还得
等 Chrome 应用商店审核，进展会告诉你。

## 署名

报告有效问题的人，都会写进发布说明致谢，除非本人不愿具名。
